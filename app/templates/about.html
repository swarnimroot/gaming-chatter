Every Monday this app gives you a one-screen rundown of the past week in gaming. Below is the pipeline that produces it — what each step does, and a glossary if you're new to terms like RSS, embeddings, or LLMs.

{# ===== Pipeline flow — 5 stages ===== #}
Step 1
Ingest
Every day we fetch fresh gaming stories from news sites, Reddit threads, and YouTube videos.
15 news sites · 10 subreddits · 6 YouTube channels
via RSS feeds + YouTube transcripts
Step 2
Enrich
An AI reads every story and tags it — which games it mentions, which platforms, the tone, the people involved.
Anthropic Haiku 4.5
one fast LLM call per item
Step 3
Cluster
Stories about the same thing get grouped. So 12 articles covering a GTA trailer become one topic, not 12 separate items.
Embeddings (nomic-embed-text) + cosine similarity
topic labels by Anthropic Sonnet 4.6
Step 4
Synthesize
An AI reads the week's topics and writes the briefing: biggest stories, market moves, risks, community vibes, what to watch next.
Anthropic Opus 4.7 + a second "critic" pass
that removes anything not in the source data
Step 5
Render
The briefing renders on the home page. Click any row to see the source articles. Export as HTML or print to PDF.
FastAPI + Jinja + HTMX + SQLite
runs entirely on your laptop
{# ===== Glossary + stack panels ===== #}
If you're new to the jargon
RSS — A simple feed format that news sites publish so apps can poll for new articles. We pull these on a schedule.
LLM — Large Language Model. An AI that reads and writes text. We use three: a small one (fast tagging), a mid one (topic labels), a large one (the weekly briefing).
Embedding — A list of about 768 numbers that captures the meaning of a piece of text. Two pieces with similar meanings produce similar number patterns.
Clustering — Grouping items that mean the same thing. We compare embeddings to decide which stories are about the same topic.
Sentiment — Whether the community sounds positive, negative, or mixed about a topic. We derive it from per-item tags and Reddit comment patterns.
Critic pass — A second AI run that fact-checks the first one against the actual source articles and strips out anything it can't ground.
Stack & numbers
  • Language: Python (FastAPI)
  • Storage: SQLite, single file
  • Frontend: HTMX + Jinja (no JS build)
  • Local AI: Ollama (embeddings)
  • Cloud AI: Anthropic (Haiku/Sonnet/Opus)
  • Cost: ~$0.35 / weekly briefing
  • Mode: Single process, local-only, single user
